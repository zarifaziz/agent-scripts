# Notion MCP

This skill connects to Notion via MCP so you can search, fetch, and update pages.

## When to Use

- You want to work with Notion pages, comments, or databases via MCP tools.
- You want to explore available Notion MCP tools and capabilities.

## Setup Notes

- The Notion MCP server uses OAuth. If prompted, complete the browser-based flow.
- Access is limited to what your Notion account and integration permissions allow.

## Usage

Ask the agent to load this skill and then use the available Notion MCP tools.

Example prompts:

- "Use notion-mcp to list Notion MCP tools"
- "Use notion-mcp to search for a page titled 'ISSUE-12345' and fetch it"
- "Use notion-mcp to add a comment to page <page-id>"
